## 📰 3. Recent Cybersecurity News/Incident

### 🚨 Vulnerability & DoS Attack: CBSE Digital Evaluation Portals (2026)

| Attribute | Details |
| :--- | :--- |
| **Target System** | CBSE On-Screen Marking (OSM) & Class 12 Re-Evaluation Portal |
| **Flaws Identified** | Unconfigured AWS cloud storage buckets, authentication bypasses, exposed evaluator portals |
| **Attack Scale** | Coordinated DoS attack peaking at **1.5 million requests in 2 minutes** |
| **Discoverers** | Gen Z student researchers (Nisarga Adhikary, Sarthak Sidhant, Vedant Shrivastava) |

#### 📝 Summary & Key Takeaways
Independent security researchers exposed critical flaws in the Central Board of Secondary Education's digital evaluation system—including hardcoded credentials and wide-open cloud buckets. Shortly after public disclosure, the Class 12 verification portal was hit by a massive **Denial-of-Service (DoS)** attack. 

This incident highlights a major lesson for enterprise deployments: **responsible disclosure protocols**, rigorous **penetration testing**, and strict **vendor risk assessments** are non-negotiable before rolling out large-scale civic infrastructure.
