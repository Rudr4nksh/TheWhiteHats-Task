## 3. Recent Cybersecurity News/Incident
* **Incident:** Security Vulnerabilities & Cyberattacks on the CBSE Digital Evaluation & Re-Evaluation Portals (2026)
* **Summary:** Independent security researchers and ethical hackers found flaws in the Central Board of Secondary Educations On-Screen Marking system. The issues included cloud storage buckets, ways to bypass authentication and open evaluator portals. After these vulnerabilities were made public the CBSE Class 12 post-result verification portal faced coordinated Denial-of-Service attacks. At the peak the attacks sent about 1.5 million requests in two minutes. This event showed how important it is to follow disclosure practices. It also showed the need, for penetration testing and careful vendor risk assessments before launching big public exam systems.
